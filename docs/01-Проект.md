# Проект

Обновлён: 24.09.2026

## Зачем

Одно место, где видно неделю и месяц целиком — время, еда, здоровье, деньги — и кто из приложений семьи сейчас зовёт, без того чтобы открывать каждое.

## Проблема

- **Итоги разнесены по четырём приложениям.** Чтобы увидеть неделю, нужно открыть «Делу Время», «Трапезу», «Дневники», «Злотые» по очереди и держать цифры в голове
- **Недельному обзору «Делу Время» нужны факты соседей** — болезни недели, тренировки, досмотренное (Р-50 «Делу Время», Р-79 «Дневников»). Приложения друг о друге не знают, и путь выбран через метаприложение (Я-12, Р-86 «Делу Время»)
- **Четыре уведомления в одно время** засоряют экран (мысль человека, 24.09.2026). Одно вместо четырёх — не сразу: сначала «требует внимания» экраном (Я-18, Р-06)

## Что заменяем

| Нынешнее | Куда идёт |
|---|---|
| обход четырёх приложений ради итогов недели | экран «Сводка» (Р-04) |
| блок «факты соседей» в обзоре «Делу Время» | ссылка из обзора на «Сводку» (Р-86 «Делу Время») |
| четыре уведомления о «требует внимания» | блок «Зовут» на «Сводке» (Р-06); уведомление — позже, Этап 4+ |
| закладки на сайты приложений | экран «Семья» (Р-07) |

## Границы

**Делаем:**

- читаем `summary.json` каждого приложения из его приватного репозитория данных одним токеном только на чтение (Я-16, Р-02)
- показываем показатели отрезков с основаниями, свежесть, «не известно» с причиной и «требует внимания» — как отдал хозяин данных
- храним увиденные срезы на устройстве — архив для будущей динамики (Р-08)
- «Семья»: ссылки на приложения и состояние их срезов

**Не делаем:**

- **не досчитываем** — ни серий, ни средних, ни сумм между приложениями, ни цвета по оценке (Я-15, предварительно; пересмотр — на настоящих данных, открытый вопрос ядра)
- не читаем сырые записи приложений и их базы на origin (Я-11)
- не пишем в репозитории данных приложений; своей синхронизации нет (Р-02)
- аналитика связей между приложениями («ел не то — заболел») и ИИ — не сейчас: нет данных (Я-10)
- тотализатор для друзей — вне семьи, не читается (Я-22)
- установка соседей одной кнопкой — браузер не даёт; отметка «установлено» — тоже нет (Р-07)

## Экраны

- **«Сводка»** — главный (Р-04). Сверху — «Зовут»: пункты «требует внимания» всех приложений (Р-06). Ниже — отрезок переключателем: идущая неделя (по умолчанию), прошлая неделя, прошлый и идущий месяц; по приложению — блок со свежестью и строками показателей
- **«Семья»** — приложения семьи: ссылка, состояние среза, как установить (Р-07). Здесь же список приложений правится
- **«Настройки»** — шестерёнкой в шапке: токен, своё название (Р-03), файл-копия, «Что нового», дата сборки

## Соседние проекты

- **`FamilyCore`** — ядро семьи, подмодуль `src/shared/`. Держит договор: форму среза, `parseSummary`, правила чтения (Я-16…Я-21). Правка договора — сессия ядра, не отсюда
- **Приложения семьи** — хозяева данных и срезов. Отдаёт срез сейчас одно: «Делу Время» (Р-87 «Делу Время»). Дальше «Трапеза», «Дневники», «Злотые» — по промптам ядра; потом «Дача» (Я-22). Приложения метаприложения не знают; обзор «Делу Время» даёт на него ссылку
- **Телеграм-бот** — будущий второй потребитель срезов, Этап 4 Плана. Новый названный потребитель: что ему уходит — правка состава сессией ядра (Я-13, Я-14)

## Распространение

Как у всей семьи: код публичный (Р-01), сайт — `goigolden88.github.io/TotalUchet/`. Посторонний, открывший ссылку, получает пустое приложение: без токена и списка приложений оно ничего не читает и никуда не ходит. У друга свои приложения и свои репозитории данных — он вписывает их в «Семье» и выпускает свой токен. Имён репозиториев в коде нет (Я-16, Я-22).
