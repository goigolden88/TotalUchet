## Этап 0 — Каркас

Вопрос этапа: ставится ли пустое приложение иконкой на телефон, работает ли без сети, доезжает ли обновление?

1. **Проект и ядро.** «Как собирается приложение на ядре?» Vite + React + TS; `git submodule add https://github.com/goigolden88/FamilyCore.git src/shared`; `tsconfig` через `extends`; `familyVite({ base: '/TotalUchet/', name: 'Тотальный Учёт', … })`; иконки — `writeIcons` ядра со своим рисунком
2. **Модель и база.** «Где лежат список приложений и архив?» `src/app/model.ts` — `App`, `Seen` дословно из Архитектуры, `SCHEMA_VERSION = 1`; `config.ts` — `dbName: 'totaluchet'`, `places` по таблице; `core.ts` — `db`
3. **Каркас экранов.** «Что видно в пустом приложении?» `Layout` с вкладками «Сводка», «Семья»; «Настройки» шестерёнкой: дата сборки, «Что нового», файл-копия; своё название (Р-03) с тестом-сторожем
4. **Деплой.** «Как код попадает на сайт?» `deploy.yml`: `submodules: true`, test → build → Pages; Settings → Pages → Source → GitHub Actions
5. **Прогон.** «Не сломались ли экраны?» `scripts/smoke.mjs` — CDP без Playwright, до первых настоящих экранов

**Готово когда:** на телефоне приложение ставится иконкой и открывается без сети; правка, выкаченная деплоем, доезжает до установленного приложения — видна по дате сборки в «Настройках»; видно, как выглядит «Тотальный Учёт» под иконкой (не обрезано ли).

## Этап 1 — «Сводка» на настоящем срезе

Вопрос этапа: видна ли неделя «Делу Время» в метаприложении такой, какой её посчитало само приложение?

1. **Токен и список приложений.** «Откуда читать?» «Настройки» — токен, проверка доступа по каждому приложению, предупреждение `canWrite`. «Семья» — минимально: добавить приложение (имя, репозиторий данных, сайт, порядок)
2. **Чтение.** «Что с каждым срезом?» `reading/read.ts` по Р-05, состояния словами; тесты — выдуманные срезы из `buildSummary` ядра, подставной `fetch`
3. **Архив.** «Что видели?» `reading/seen.ts` — запись в `seen`, последний увиденный (Р-08)
4. **Показ.** «Как прочесть срез глазами?» `view/periods.ts` — отрезок экрана, поиск по концам; `view/values.ts` — значение словами; `view/attention.ts` — «Зовут». Тесты на всё
5. **Экран «Сводка»** по Р-04, Р-06
6. **Проверка на настоящем** — `summary.json` «Делу Время» из их репозитория данных, токен даёт человек. В репозиторий из него ничего не попадает (Р-01)

**Готово когда:** на телефоне и компьютере «Сводка» показывает срез «Делу Время» — строки, основания, «посчитано / по записям по»; число в строке совпадает с числом на экране «Делу Время» за ту же неделю; без сети — последний увиденный с датой прочтения; приложение без `summary.json` — «срез не отдаёт»; неверное имя репозитория — «токен не видит репозиторий»; прошлая неделя и месяцы переключаются.

**Этим закрывается Этап 3 ядра** — «первый экран читает настоящий `summary.json`». Сказать человеку для сессии ядра.

## Этап 3 — Рядом: сопоставление групп соседей

Вопрос этапа: как увидеть рядом строки разных приложений про одно и то же, не складывая их (Я-19, Я-15)?

Начинается, когда срез отдаёт второе приложение. Настройка человека «эти строки — рядом», по `key`; переименование группы «Делу Время» меняет ключ — настройку поправляет человек (Я-17, «Цена», п. 3). Решение — в начале этапа.

## Этап 4 — Телеграм-бот

Вопрос этапа: приходит ли сводка недели в Телеграм в выбранное время без открытого метаприложения?

Черновик, решается в начале этапа:

- **Исполнитель** — плановый workflow GitHub Actions: читает срезы токеном из секретов, `parseSummary` ядра, текст — теми же функциями `view/`, отправка — Bot API. Сервер не нужен
- **Где живёт.** Логи Actions публичного репозитория видны всем (Р-01): либо **отдельный приватный репозиторий** (бесплатных минут хватит; `TotalUchet` — подмодулем ради `view/`), либо здесь, но в лог — ничего из среза. Рекомендация — приватный
- **Расписание Actions неточно** — опоздание на минуты, бывает до часа («Делу Время» отвергло Actions для напоминаний по этой причине). Для недельной сводки терпимо. В публичном репозитории плановые workflow выключаются после 60 дней без коммитов — ещё один довод за приватный
- **Секреты:** второй экземпляр токена чтения, токен бота, id чата
- **Бот — новый названный потребитель** (Я-13, Я-14), **Телеграм — третья сторона:** что ему уходит — правка состава договора сессией ядра, **до кода**
- **Бот с командами** — позже: нужен сервер или вебхук
