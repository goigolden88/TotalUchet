### Сессии Claude Code

Запускать из корня `TotalUchet`: история бесед привязана к рабочей папке. Между этапами — `/clear`, `/compact` — для середины этапа. Перед `/clear`: дерево чистое, всё запушено, и по одному Журналу понятно, где мы и что дальше.

### Ядро — подмодулем

- **Клон** — только `git clone --recurse-submodules`; уже склонированное — `git submodule update --init`. Иначе `src/shared` пустой, сборка падает непонятно
- В `deploy.yml` у `actions/checkout` — `submodules: true`
- **В `src/shared` не запускать `npm install`** — появится вторая копия React (Я-02)
- **Обновление ядра** — `git submodule update --remote src/shared`, тесты, сборка, прогон, коммит указателя. Перед пушем `git status` чистый **и в подмодуле**: `git -C src/shared status`
- **Нехватка в ядре или противоречие с договором** — не правка `src/shared`, а слово человеку: это сессия ядра, решение Я-NN. Потом — обновление указателя здесь

### Сессия ядра — что ей отсюда передаётся

Правки договора — формы, состава, правил чтения — решает только сессия `FamilyCore`. Отсюда — список в Журнале, раздел «Для сессии ядра», человек несёт его туда.

## Разделение работы

**Claude Code — и «что строить», и «как».** Он видит настоящие файлы ядра и приложений и проверяет факты. Режим планирования — когда обсуждаем и ничего не трогаем.

**Чат (Claude Desktop, claude.ai) — когда компьютера нет под рукой.** Из чата сюда приходят готовые куски markdown и список того, что переделать в коде. Настоящие срезы в чат не носить.

## Правила ведения документов

- **Не менять задним числом.** Отмена решения — новая запись со ссылкой
- **Решения записываются в момент выбора**
- **Журнал обновляется в конце каждой сессии**
- **Перед пушем — `npm test`, `npm run typecheck`, сборка, прогон** — итог по коду выхода, а не grep'ом по выводу
- **Видимое изменение — строка в `src/changes.ts`** в том же коммите
- **План содержит только предстоящее**
- **Правки файлов с кириллицей** — инструментом правки или скриптом-файлом из папки сессии, не heredoc Bash: он съедает `\n` и `\` (опыт «Трапезы» и ядра)
- **Чужие репозитории — только `git show`**, не файлы с диска: рабочие копии в CRLF врут
